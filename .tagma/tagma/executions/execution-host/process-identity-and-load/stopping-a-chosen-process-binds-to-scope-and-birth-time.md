A PID can change owners between the line shown and the act. So generic ending admits only the identity the latest Load read enumerated, except Tagma's own processes and ones this user cannot signal, and re-reads its native witness before every signal. A live execution stops by its own act; processes and programs left after it end by this generic ending. A taken signal never proves finishing: the answer separates observed departure, survival, and measurement-or-signal refusal.
