Work that cannot be trusted with the host's files, network or graph runs in a sandbox — a guest environment from a project commit or a prebuilt tree with dependencies. The module owns preparing and freeing sandboxes, building such trees, and carrying the files the work left into the checkout as a regular write. What to run inside is decided by the agent that received the sandbox.
