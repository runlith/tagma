- **Before raise.** In the handover gap the old logic already dropped `host.sock` while the new one doesn't listen yet: presence reads as Absent, and raising without waiting would launch a second holder onto the same table.
- **What it waits for.** Registration names the candidate's digest, and status answers with admission `open`: this tells the new logic apart both from the departing one (its admission is already fenced) and across a change of a single boot entry where the digest doesn't change. The new logic writes its witness into registration before opening the endpoint.
- **Foreign-build logic in registration.** The successor asks it once per witness to yield by signal (`LogicYield`, road [[0123fde2]]). Logic departing after Yield skips the signal and exits; logic left after a failed handover or raised by holder rollback checks the candidate and yields or writes a refusal. A dead witness (`Gone`) means the holder raises the next logic, and the wait continues.
- **The verdict is fact only.** `Arrived`; `Unheld` — the writer claim is free: there is no holder, the pre-raise reshuffle puts the candidate in place; `Refused` — the asked logic's refusal in `yieldRefusalPath`, naming this candidate or none; `Fallen` — the load refusal of this digest's logic stands beside its boot entry: it fell before ready while the holder keeps the claim ([[c8a4efca]]); `Kept` — registration of the wrong schema or directory, the foreign-build logic has no witness, the signal can't be delivered, own-digest logic answers with something the server can't read, or the refusal names another candidate or cannot be read. A failure of one's own read — of registration, `lsof`, of clearing an old refusal — is no fact about the logic: it is asked again. While the holder holds the claim and the logic is alive or rising, the wait lasts as long as it takes: on a slow machine boot takes minutes. Status to own-digest logic goes with no deadline; an answer or a broken connection ends it. The claim is read through the `ClaimHolders` port of the platform adapter (on macOS by `lsof`), so no more than once a second; frequency only decides when to ask again.
- **Order inside a look.** Arrival is read before the load refusal: a logic that fell once and came up on the holder's next raise reads as arrived. Placement removes the placed digest's load refusal and the sweep those beside swept boot entries, so a load refusal read in the wait was written during it.
- **The refusal names its candidate.** A logic of this build writes a `YieldRefusal` record with the digest it read at `bundle.next`; a torn channel writes none, since it answers no ask and the logic the holder raises next is asked again. A logic of an earlier build writes one bare line, still read as the answer: the standing foreign logic is usually that earlier build, so the distinction serves only servers of builds after the one that writes it.
- **With no fact.** Own-digest logic, alive and hung after Welcome, holds the raise forever: nothing publishes such a hang. So does logic that dies at load without a typed failure — a kill, a runtime that does not start: the holder raises it again and nothing writes a cause. A bare refusal an earlier build writes on a torn channel still reads as an answer to this request.
