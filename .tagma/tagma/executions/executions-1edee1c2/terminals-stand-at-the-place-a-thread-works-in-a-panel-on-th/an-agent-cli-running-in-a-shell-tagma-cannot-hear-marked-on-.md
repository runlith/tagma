Adoption needs the CLI's hooks and a shell born with its key; a CLI without Tagma's hooks, one under tmux, or one in a shell opened before the key existed runs unseen. The shell's process evidence could still recognise an agent CLI binary in the foreground and mark the tab: an agent works here that Tagma does not hear. Uncertain because recognition by binary name is text, which a mark may use but no attribution may ([[e67f884d]]).
