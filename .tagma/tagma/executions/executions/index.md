The processes Runlith starts for a person or an agent — the operator terminal, an agent shell command, a harness CLI, a managed check — run in a separate execution host, and this package is the contract both sides of the cut speak. It defines what an execution is: identity and phases, who owns it and who may type into it, where its bytes and screen live, how much of the machine it may take, and what proves its ending. With it come the port every verb goes through, the single-host socket client, record readers that outlive the host that wrote them, and a spawner whose children look like the platform's own children. For internal processes under Bun the package offers a spawner over native streams and the exit promise; the choice between it and the execution host stays with composition. The package holds no host: which host to contact, who may act, and what an answer means is the caller's decision.
