Tagma's developer sees what a new user gets from the published release without leaving Tagma Dev: the module opens the release in a world with a home of its own beside the running Tagma Dev and starts that world over from nothing in one act. It owns choosing and keeping the release, stopping and removing the world and reopening it; what macOS does for it — unpacking an image, the keychain, launching with a home, forgetting the bundle — is its host port, filled by the macOS release platform. It exists only in the developer build.
