**Value.** An edit to law or dictionary inflates what every new thread reads before its first word. The writer sees at once what the write cost and does not silently overload the context of all future agents.

**How.** The write's answer itself carries the startup-instruction size and its change.

**Behaviour.**
- Writes to blocks carrying law, writes to tags and catalogs, rule enabling and delivery, replacement and its withdrawal name the price.
- A batch, deletion, restore, and sources edit name the price only when it is nonzero.
- When measurement fails, the write still takes effect, and the answer names the cause.

**Limits.** The project's default agent startup instructions are measured. When that agent is not native, the price is not measured; when it is graphless, a tag edit prices zero. Law written by another session between measurements lands in this write's cost.
