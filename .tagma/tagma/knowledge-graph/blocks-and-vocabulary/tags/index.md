The tags this project declares. Each node here is a declaration: its fields say what nodes carrying the tag hold, which edges they may point along, which gates their writes are held to, and which of the core roles they bind; its body is the prompt those nodes are read with. Installed catalogs and tags written by hand stand side by side, because they are the same thing.
