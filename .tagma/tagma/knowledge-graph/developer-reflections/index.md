A Tagma developer collects agents' friction with Tagma itself into the graph of its sources: the module provides the `file_reflection` and `read_reflections` operations, finds the Tagma graph and carries the prompt section about friction. An entry is born stealth, since it carries the filing machine's places and projects; a caller chooses team to publish it. A release has no Tagma graph, so release composition does not connect the module; the `#reflection` type, the reflection answer and the `tagma` alias stay with the graph.
