title: Links between blocks are written as an edge, not as a list of references in the body

tags: ["rule"]

A block's page already shows its edges and references, so a “Links: [[a]], [[b]]” line only duplicates it. A `[[name]]` reference in the body stands only inside a sentence explaining how the blocks connect.
