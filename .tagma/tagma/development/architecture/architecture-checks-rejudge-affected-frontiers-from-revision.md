A partial reading answers its requested and affected paths: a changed declaration can make an unchanged caller or literal a new violation. Blob and revision identities let the checks reuse facts across commands and checkouts; a missing or distant starting index requests an explicit remeasure instead of turning a commit into a repository scan.

The caller check follows declared capabilities through syntax and local/imported provenance, not a TypeScript type checker. Generic, utility-type and inheritance flows, untyped argument propagation, mutable collection storage and pattern loads are outside its proof. Metadata and lifecycle imports alone are not model calls, and a row's type alone is not a runtime row read. Coupling readings carry their module territories and workspace export maps with the revision so boundary changes rejudge the affected imports.
