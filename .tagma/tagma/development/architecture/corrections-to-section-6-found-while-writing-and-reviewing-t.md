Corrections to approved section 6 ([[be799808]]) found while writing the package and app cards. Each is the card author's evidence; the tagma agent applies them to section 6 when section 7 part 2 closes.

1. **`llm` neutrality is more than moving capture.** Shipped `llm` hardcodes Tagma: `profiles/DevinCustomTools.ts` (`SERVER='tagma'`, gateway note), `profiles/muse.ts` / `opencodeGo.ts` User-Agent, `oauth/FileTokenStore.ts` failure text and model provenance. Product identity becomes a caller-supplied input; recorded vendor wire bytes are preserved.
2. **`agent-sources → agent` is service + type, not type-only.** `WorkflowDirectories.ts` calls the runtime `parseWorkflowDefinition` (G2).
3. **`agent-tools/workspace` is not browser-safe today.** It is Node/Effect runtime and imports `hostWorld`. Its types separate from its runtime; `changes/measure` is granted to `change-record` (G2).
4. **MCP pools are per project inside one process**, not one pool per process: `McpServers.ts:184–186,330–338` keeps `Map<projectId, Pooled>`; flattening would mix declarations and secrets (G2).
5. **`mcp/sdk` has consumers.** `agent-tools/websearch.ts:4` imports its type, two CLI suites its functions; the entry becomes a testing entry after they move, subject to the F064 check (G2).
6. **App feature table (§6.5.3).** Cross-feature reading marks and panes go to `lib/shared/reading/`, `Visits` to `features/workspace/`, `ReadState` stays in `features/graph/reading/`; `features/reading/` dissolves (G4).
7. **`read_path_exists` is graph's** (the served checkout with realpath protection): `features/executions` reads graph's wire for the terminal file-link check (G4; decided in the server-card review).
8. **Server answer shapes the app still computes itself:** settings resolution and worktree merge admission. The server must answer them before the app stops calculating them; domain logic leaves the app then (G4).
9. **`utils/process` is server-only.** §6.2.2 says every utils entry is browser-safe, but `src/process.ts:1–6` calls `process.kill`; P0 marks the other resolved entries browser and keeps `./process` `node`/`bun`.
10. **`paging` cursor errors remain distinct.** `readCursor` refuses malformed/undecodable cursors with `bad-cursor`; only a well-formed cursor of another question refuses `cursor-stale`. On an encoding change keep a past decoder or report `bad-cursor` and restart. `agent-tools/pageFamilies.ts` keeps the operation-specific `cursorField` accessor over `paging.cursorSelection`.
11. **`package-boundary`'s unjudged result must reach the rule.** `src/index.ts` adds `PackageBoundaryReport.unjudged` and changes `browserEdges` and source reads to preserve missing, unreadable and unsupported reach rather than discard or throw. `enforcement` carries that arm to its gate verdict; a partial browser walk never reads clean.
12. **The desktop also reads installation layout.** Server card §7.5.9 must put `DEFAULT_PORT`, `SURFACE_DEV_PORT`, `HOST_APP_BUNDLE`, `HOST_MAIN` and the already named installation file/layout constants into `installation/contract/wire/layout`; `src/installation.ts`, `src/config.ts`, `scripts/dev.ts` and `scripts/build-host.ts` have five import statements over them. Desktop is the second reader, so the numbers cannot be moved to one supposed reader.
13. **`window-behavior` has a renderer and controller reach.** §6.2.2's browser list expands beyond `contract/*` to pure `runtime-core/presentation`, `runtime-core/reduce` and `bindings/controller` after the resolver checks them. All seven `host-electron/*` and two `native/*` entries remain server/native-only.
14. **SSR entry conditions follow actual imports.** `layer/Platform.ts` must not construct `BrowserLive` at import; `./Platform/browser` holds browser construction, while `./Platform` is SSR-safe and `./sveltekit` is both `browser` and `ssr`. `@runlith/query/repo` is also `ssr` (server cache and hydration), not browser-only. A no-DOM import checks the seam.
15. **Browser tool-display vocabulary has one kernel door.** `packages/agent/src/tool/display.ts` defines `@runlith/agent/tool/display` for `toolDisplayOpensByDefault`; `chat-ui/ActivityStep.svelte` and `rowEstimate.ts` import that, never mixed runtime `@runlith/agent/tool`. The protected kernel card is updated by its architects.

Keep old answer reading under K2; only then remove the UI's `SettingsCatalog.answerOf` layer-precedence fold.

Only then remove the app's `hardBlocked`/`baseBusy` and locally inferred defer.
18. **Thread attachments remain binary HTTP resources.** `api/threads.ts:380–396` keeps the POST upload and GET download routes outside the generated operation catalog. The app's one typed HTTP door uploads `{threadId,projectId,mediaType,Uint8Array}` with project query and MIME header, decodes the 201 attachment metadata and typed missing/refusal; the server supplies the download URL.
19. **Boot precedes the host wire.** The server writes `boot.json` before starting a selected host artifact, and the host decodes it before socket hello. The current card allows optional-only boot extensions preserving old required fields; an incompatible boot transition needs an artifact-version-selected codec and its own decision. Section 2 D7's wire range cannot protect the boot file.
