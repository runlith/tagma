The facts of a source file — its exports, imports, uses by value or type position, and type shapes — are a function of its git blob alone, so `store.ts` keeps them per blob in `<git-common-dir>/runlith-law/declarations.sqlite`, with the places a blob stands at and the import links and shape keys that find importers and copies. The index resets whenever a file that defines it changes. No complete findings are kept for any revision.

Only a whole reading (`check_rules` over "all", a remeasure) builds the index: it lists the tree, parses every blob it lacks and seeds the packages map. A judgment of a change never scans and never computes a whole result: it derives the revision's index from the nearest of the last indexed ones by `git diff-tree`, and fails with the setup action (`check_rules` over "all") when none lies within 5000 changed files or a packages state is missing. It computes the owners the change can move — the changed files and the exporters whose consumption edges (import, re-export, load) it added or removed; for repeated declarations, every file in a group of a changed shape key on either side — and answers their findings on the base and on the tree from blob facts, with `covered` listing exactly those paths plus the requested ones. A path in `covered` carries all its findings of that version, so the answer agrees with the remeasure on those paths and says nothing about the rest.

A `package.json` edit moves something only when the package's name, exports or entries change, read from the changed manifests alone: the files importing that package by name are re-resolved before and after, and its entry or published targets are re-judged. A commit finds a package by name, among the directories above a file, or among the packages whose entry or export targets lie outside their directory (looked up by the exact target, its extension and index spellings, or the static directory of a glob) and never lists the packages; two packages with one name resolve to the later directory. Those reverse rows follow the changed manifests only, and a moved package's outside targets are listed on both versions so they are rejudged. A pattern load (`import.meta.glob`, a template `import()`) is resolved against the listing of its static directory only. A load whose static directory is the repository root, and a change of the root package's name, exports or entries, cannot be judged on a commit and fail asking for the remeasure.

An export is dead when no production file imports it; an exported function also needs a runtime caller, so type-only imports and `typeof` positions do not count. Reach is direct: an importer that is itself unused still consumes. Test files, `testing` folders and declaration files are matched by the `tests` globs and are neither consumers nor judged. A referenced type counts by the declaration it names — the module an import resolves to, or the declaring file for a local one — not by its spelling, so equal members that point at different `Row` types are no repeat and aliases of one imported type are. The module an import resolves to goes through the same resolver as dead-code — relative, alias and workspace package exports — so a package public path and a relative path to one file name one declaration. A barrel that re-exports the declaration, and a local `type R = Row` alias, still name another module and miss the repeat; they never invent one.

Repeated declarations mean direct aliases of imported types, same-name equal types across modules with at least three members or alternatives, or copies of an exported production dependency's type meeting the same threshold. Short shapes do not establish a shared concept even under one name; direct imported aliases need no structural threshold. Equal shapes under different names in unrelated modules and shapes within one module do not prove a shared-type copy. The revision's module cards and production relations decide ownership, shared with coupling through `architecture/boundaries.ts`; card edits rejudge the changed owners and their declared importers. Fingerprints name the export or shape and the file, never a line, so an edit above a declaration keeps its debt.
