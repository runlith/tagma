This covers:
- a crossing breaking a floor;
- a colliding name;
- an unsuitable type;
- a cost growing with history.

Each changes where it is produced, in the same change that met it. The alternative is debt owned by the task removing it at that owner. No shim hiding the problem from inspection, and no local copy.
