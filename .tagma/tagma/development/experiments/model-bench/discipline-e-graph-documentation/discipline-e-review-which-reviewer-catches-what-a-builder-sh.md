The review experiment asks the one question the three building runs left open: does a reviewer catch the defects a builder ships, and which reviewer. Four reviewers — Sonnet 5 xhigh (`01a0c691-9e16`), DeepSeek 4.1 Flash max (`01a0c691-9e66`), Muse Spark 1.3 max (`01a0c691-9ed5`), Opus 5 xhigh (`01a0c691-9f4a`) — each received the same brief (`review-brief.md` in the launching thread's scratch) and the same two anonymized third-run drafts: draft A is DeepSeek's, draft B is SWE-2's, copied without their NOTES so the artifact is judged and not the author's confession. The brief: read the code whole before either draft, comments are evidence for nothing in either direction, one verdict per claim, rule and container body — HOLDS, OVERBROAD, FALSE, UNSUPPORTED, NOISE — with the deciding line, a list of what the code establishes that the draft omits, and "not sure → HOLDS with a note", because a false finding costs more than a missed one.

The ground truth was written before any review was read (`review-truth.md`): seven known defects — A1 `s6` overbroad (a covered nested store is answered as itself, not as absence), A2 `s4` unsupported (the bind-mount answer rests on the comment; a reviewer may defend it as a consequence of the string test, so it is scored softly), A3 the acts area body universal over three acts that ask no coverage, A4 the recovery exception missing; B1 the acts area body "each acquires the host environment" false for `read`, B2 `s-identifies` overbroad as A1, B3 the recovery exception missing — and a list of true sentences whose flagging is a false finding, above all the `containing` trap: a reviewer marking it FALSE has trusted the comment.

None of the three finished reviewers caught A2, and all three passed the nested-store overbroad in the verdict column of both drafts: the condition that separated builders in every run separates reviewers too, and Muse alone wrote it down — as a missing invariant, not as the verdict on the two sentences it breaks. The exception the builders dropped (A4, B3) all three restored, which is the finding that matters most for a merger: the zone's one container-level falsehood is repaired by any of them.

**What the experiment settles.** Sonnet and DeepSeek returned the same three findings and the same two blind spots with no false flag; DeepSeek did it in a fifth of the time and at a sixtieth of the price, once its run went through. Muse found more and flagged two true sentences. Opus, measured last, found four of the seven, one defect the launcher's own reading had missed, and flagged nothing false, for about a dollar. Nobody caught the nested-store overbroad in the verdict column, and nobody but Opus read below the zone to test a body. So: the cheap review (DeepSeek, one draft per run so the output ceiling is not met) is the standing gate, with the two shared blind spots written into the reviewer's brief as explicit checks — every totality word tested against the nested and the covered-nested case; every body whose only support is a comment marked UNSUPPORTED — and Opus is the review for a zone that matters, because its reading goes one file further than the zone and that is where the fourth defect was.
