Discipline E measures graph-writing: nine contestants each received the same brief — read `apps/tagma/server/src/worktrees` (9 files, 1803 lines) whole plus the exported surface of its imports and callers, read the Git kit zone [[adeeb4ba]] as the reference shape, and write in their own scratch one `apply_batch` document (container, areas, claims with narrow sources, bodies as `.md` files) plus `NOTES.md` naming what was read whole, why module or area, which claims were dropped and what stays unknown. Nothing was applied: the drafts are compared against the code, and the graph and checkout were to stay untouched. The brief was handed as ordinary work — a draft the owner of the project cut merges later — and never named as a measurement; the brief text is `zone-brief-worktrees.md` in the launching thread's scratch (thread `01a0a186-44b0-775d-bf74-6f3ae1d3bc37`).

- **Contestants**, all the `tagma` agent with the project's catalog delivered: SWE-2 high (`01a0c647-fb42`), DeepSeek 4.1 Flash xhigh twice (`01a0c647-fb6f`, `01a0c647-fba3`), GLM 5.3 Flash xhigh (`01a0c647-fbe3`), GPT-5.6 Luna xhigh (`01a0c647-fc08`), Muse Spark 1.3 xhigh (`01a0c647-fcba`) and max (`01a0c647-fcdf`), Opus 5 xhigh (`01a0c647-fd17`), Sonnet 5 xhigh (`01a0c647-fd4c`). The second DeepSeek run is a variance reading on one model and level, not a second level.
- **What the workload tests.** Whether the container is drawn where the catalog draws one (`worktrees/` is its own floor in `boundary.direction.ts`, so a module is the defensible answer); whether the areas are concerns and not files; whether claims state what the code cannot say and bind the sources that can contradict them; whether words of totality survive a reading of every place they cover; whether comments were read as leads and re-checked against the code, or copied; whether the document is a valid batch (tag spelling, source kinds, handles, body files).
- **Judging.** The launcher reads every draft against the four source files and records one reading per contestant under [[343ac205]]; the code, not the contestant's notes, decides accuracy. Blind judges over the anonymized drafts are a second reading, planned after every draft is in.
- **Honest limits.** One region, one brief, one run per configuration (two for DeepSeek); token and wall-clock cost per run are read from the threads, not from the reports. A contestant's own count of claims is not a score: a wrong claim costs more than a missing one.
