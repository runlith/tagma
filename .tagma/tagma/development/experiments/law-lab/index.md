The `law-lab` project (id 39, `/opt/workspaces/law-lab`, team graph) — a synthetic project built with Bun, Vite and React: a three-layer expense-tracking app (`packages/domain`, `packages/ui`, `apps/web`). On it we check that Tagma's law mechanisms work for real — rule delivery, checks and their judgement, strictnesses, debt, the module map, project programs, the commit gate, judgement over several sessions' lines — and think them through so they serve any project, not just runlith. Global rules are switched off in law-lab (`rules.global.enabled = false`) so only the project's law shows.

Mechanisms are studied, not model behaviour: the researcher thread does the steps itself — writes code with file tools, calls operations and reads their replies. What to check next is decided along the way. Each check is a child #experiment: hypothesis, the law-lab commit it repeats from, observation, conclusion, and on a separate line — what the user had to know or do on their own.

Only what a normal project sees is written into the law-lab graph: rules, modules, tasks about code. Experiment records live only here, same as for the [[4e20292e|polygon]].
