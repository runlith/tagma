The `polygon` project (id 33, `/opt/workspaces/polygon`) — Shopfront, a small shop API built with Bun: goods, orders, money in cents. The product is fictitious; its agents do not know it and work as ordinary implementers. The runlith thread gives them tasks via `spawn_agent project: polygon` (the capability from [[1013e071]]), speaking as the customer.

Why: to watch live how an agent and Tagma behave on controlled code — law delivery, gates, refusals, landing, Team, interface — and to accumulate repeatable runs for comparisons and benchmarks. Each run is a child `#experiment`; its setup names the polygon commit it repeats from.

Only what an ordinary project sees goes into the polygon graph: rules, tasks, notes about code. Experiment records stay here only.
