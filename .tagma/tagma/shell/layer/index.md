Runlith's client apps are one service graph, not components pulling at each other: a feature declares what it needs, the manifest names the provider, and the graph gives each instance a lifetime by its place — app, project, thread, a single panel. The package owns the vocabulary an app is declared in, the core that builds and tears down instances in open scopes, and the bindings connecting the graph to Svelte, to SvelteKit load and to a single server request. The ladder's rungs, the meaning of each key and every door to the outside world stay with the app; of services it gives only those no manifest can do without: failure reading, scope handoff, chunk prefetching and snapshots.
