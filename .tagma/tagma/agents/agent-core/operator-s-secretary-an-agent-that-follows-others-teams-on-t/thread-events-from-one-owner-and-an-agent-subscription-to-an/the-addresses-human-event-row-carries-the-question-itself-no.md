The "addresses a human" event row carries the question itself, not the answer's start.

The event carries the root's last answer start. When the question hides in the middle of a long report, the subscriber's row shows only the start: "Notification-module review summary… send key…". Finding the question means opening the lead's answer — as in the [[6d391f5d]] check.

Idea. This event's row carries the text passage holding the question.
