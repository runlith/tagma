Every agent of the monorepo — a Tagma thread, a harness in its own world, an assistant — works inside this package. It owns what an agent is: a loop making one turn, a tool contract with a single door through which every call travels, a thread outliving its own runs, and a run machine bringing a turn to its end through a dying process. Storages, models, tools, and the command host are supplied by the product, which mounts the planes it needs.
