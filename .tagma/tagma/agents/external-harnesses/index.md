Claude Code, Codex, and other CLIs run as Tagma threads, and this module owns that binding: what Tagma installs into a CLI — hooks, skills, workflows — accepting their sessions, observations from hooks, answers to their permission requests, and the operator's words into a running CLI. A thread rides one of two transports: `terminal` (a `{adapter: 'terminal'}` binding in the thread core row; the facet holds the process and observations, not the transport choice) — the CLI in a PTY that Tagma sees through hooks and the screen — or `acp` (the binding and capabilities in the thread core row: `adapter: 'acp'`, `agent` the hosted native agent) — an agent the protocol driver leads over ACP from a held process, and then the turn, questions, law, and report go over the protocol while hooks stay silent. The CLIs themselves are foreign programs; the module knows about them only what is visible through their files, hooks, screen, and protocol.
