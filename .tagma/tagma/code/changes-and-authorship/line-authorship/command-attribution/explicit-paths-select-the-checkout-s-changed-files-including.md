Explicit paths select the checkout's changed files, including nobody's.

An explicit file or directory in paths sets the delivery area regardless of authorship: changed paths come from git status, and tracked-file deletions are additionally checked against the index and disk in the named area, because fsmonitor can miss a deletion. Holdings judges their holders the same way as held paths. Explicit paths also narrow held paths taken through taking. Without paths, landing takes paths where a fresh Holdings judge names one of the selected sessions as holder, including unproven; unfinished records only supply candidates for that judge. A candidate without a judge answer stops landing with `walk-cut`: a missing answer never proves lines absent. An overwritten own edit never selects a path with remaining foreign or nobody's lines, even when it is program-written. Stored command observations stay a hint about unlanded paths. The exception is a path with reason `team`: the tree root that took its member through taking carries it without paths when every observation on the path is `team` of that root, the latest observation retains a digest matching the current bytes, and no foreign holder remains. The same observed bytes ride beside the carriers' typed lines in that file, with the digest checked again at slicing; a changed file or a digest-less observation grants no carry. A path with foreign holders stays outside this team-only selection. A caller whose records the record never sees — a thread of another harness, a Claude Code session outside Tagma, the operator — is never a holder in the record: their edits bypass Tagma tools and land nobody's. So they land only explicit `paths` in the checkout where their call stands, and in them they carry nobody's lines as their own (one hand on the file, like any holder); independent foreign lines are separated, dependent ones land with their authors, the operator's lines only through `taking`. The rules judge judges nobody's lines as their delivery, and commit steps and the judge run under their own actor (another session, another harness's thread), not the operator. Without `paths` and `taking`, both landing and check_rules over a change refuse `no-record` rather than answering with an empty change. A native session carries nobody's lines beside its own only through the matching team observation or explicit `whole`; other unowned lines remain outside. Nobody's lines count the same for edit links: an edit with a nobody's line inside someone else's uncommitted insertion pulls the insertion with its author. Native landing follows nobody's links only when it carries the matching team observation; otherwise a required unowned replacement refuses `lines-held` with `whole` as the way out before the slice is assembled.

Explicit selection never attributes authorship: independent foreign lines are separated, and lines the selected edit depends on land with their authors. `whole` holds files or directories among the selected paths and carries their working bytes whole; it never adds paths by itself. A program file is carried whole automatically, foreign authors are named in `carried`; the graph store never enters a delivery.
