Nobody's lines (`external`, `steps`, `unattributed`, `released`) leave by commit when they ride a landing: a whole region on the path with no other holders, or `whole`, or a manual commit. Question: should the operator or an agent get a "these nobody lines on the path are mine" act that writes a record line on the thread's behalf.
- Against: it is one more entry, and `whole` plus the "without other holders nobody rides" rule cover the common case.
- For: nobody's next to another thread's lines otherwise hangs until that thread lands.

The frequency of nobody paths in mixed regions after S2–S5 is built will decide.
