An approval covers one selected checkout: lines of another checkout appearing while awaiting never redirect the call, and the receipt and `left` describe only its tree. `taking` adds line holders inside the selected checkout but never selects the place; when one's own lines don't set the place, the foreign checkout is named explicitly. Rule judgement, commit shape and tasks belong to the place's graph; execution authorship and custody to the holder's home: mixing these coordinates would either judge another's commit by home law or strip the session of its lines.
